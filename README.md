## Como editar

1. Abra `index.html` no VS Code — todo o conteúdo, estilo e scripts estão neste arquivo.
2. Vídeo institucional: preencha `const YOUTUBE_ID = "";` no fim do arquivo com o ID do vídeo no YouTube.
3. Commit + push na branch `main` ⇒ a Vercel publica automaticamente.
